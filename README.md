# Échoppe Tech & Mode — front web

Interface React (Vite) qui consommera l’API Strapi du projet de groupe IRIS.

## Démarrer

```bash
cd frontend
npm install
npm run dev
```

Puis ouvrir l’URL affichée (souvent `http://localhost:5173`).

## Secrets

Copier `frontend/.env.example` vers `frontend/.env.local` et y mettre l’URL Strapi.
Ne pas pousser le token sur GitHub.
